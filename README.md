# CombatTag

CombatTag для Paper 26.3:
- метка боя на 20 секунд после удара;
- обновление таймера у обоих игроков после каждого попадания;
- поддержка ближнего боя и снарядов, выпущенных игроком;
- оставшееся время отображается над хотбаром (Action Bar);
- при выходе из боя игрока предметы из инвентаря, брони и второй руки выбрасываются на землю, затем запускается обработка смерти.

## Требования
- JDK 25
- Maven 3.9+
- Paper 26.3

## Сборка
В папке проекта выполни:

```bash
mvn clean package
```

Готовый файл появится здесь:

```text
target/CombatTag.jar
```

Скопируй `CombatTag.jar` в папку `plugins` сервера и перезапусти сервер.

## Важно
Сначала протестируй на тестовом сервере. Наказание за combat-logout выбрасывает вещи на месте выхода. Если на сервере установлены другие плагины на смерть/инвентарь, проверь совместимость: они могут менять стандартную обработку смерти.
